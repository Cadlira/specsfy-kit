# ADR-003 — Profiles represent intent

## Status

Aceita.

## Decisão

Stack é evidência técnica; profile é intenção; specialist é conhecimento. A
detecção somente sugere. Java 21 com Spring 4 pode ser manutenção ou
modernização e requer escolha explícita.

## Consequências

Profiles são composáveis, orientados a dados e possuem conflitos declarados.
